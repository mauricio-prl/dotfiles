Check the last commits on the current branch, and fill the following template:

```md
#### What?

- What this PR is changing in the code.

#### Why?

- Why we are performing these changes.

#### How to test

- Help the reviewer testing the functionality of your code.
```

don't need to be extremely formal, and please be short we don't need a full bible in each pr description.
